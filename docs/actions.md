# Actions

Generated by `tools/build_actions.py`. Every SPH setting type of the official
[Growatt OpenAPI page "SPH parameter settings"](https://www.showdoc.com.cn/262556420217021/6129761750718760) is one action. Types, parameter
positions, ranges and values follow that page. Actions need the official API (API token);
while the integration runs on the portal fallback they fail with an error.

After a write the settings entities are read again with the next poll that is at least
5 minutes after the last settings read (Growatt rate limit).

## Raw access

| Action | What it does |
|---|---|
| `growatt_web.write_parameter` | Sends any setting type of the official API (mixSet) with up to 18 raw parameters. |
| `growatt_web.read_parameter` | Reads one setting directly from the inverter (readMixParam) and returns the answer. |
| `growatt_web.get_history` | Returns the stored 5-minute data sets of up to 7 days (mix_data). |
| `growatt_web.get_alarms` | Returns the alarm records of the inverter (alarm_data). |

`read_parameter`, `get_history` and `get_alarms` return the answer of the API as action
response (`response_variable` in a script or automation).

## Example

```yaml
action: growatt_web.set_charge_periods
data:
  charge_power: 100
  charge_stop_soc: 100
  grid_charge: false
  period1_start: "00:00"
  period1_end: "04:00"
  period1_enabled: true
  period2_start: "00:00"
  period2_end: "00:00"
  period2_enabled: false
  period3_start: "00:00"
  period3_end: "00:00"
  period3_enabled: false
```
